# homebrew-tap

Homebrew tap for [Adrij Shikhar](https://github.com/adrijshikhar)'s open-source tools.

## Usage

```sh
brew tap adrijshikhar/tap
brew install adrijshikhar/tap/<formula>
```

`brew install adrijshikhar/tap/<formula>` taps automatically, so the explicit
`brew tap` step is optional.

## Available

| Formula | Description |
| --- | --- |
| [`binsight`](https://github.com/adrijshikhar/binsight) | A local MySQL & MariaDB binlog viewer and analyzer for developers |

## Notes

Casks and formulae here are generated and committed automatically by
[GoReleaser](https://goreleaser.com) when a project cuts a release — edit the
source project, not this repo.
